# AQ40 — доработка тактик

Ветка `raid/finish-aq40`, коммит `9e896a49`, база `raid/all` на `e1e32dda`. В исходном audit.json три встречи имеют статус partial. Остальные шесть, включая C’Thun, имеют статус good.

## Fankriss the Unyielding

В boss_fankriss.cpp Entangle выбирает одного игрока, а SummonHatchlingWaves создаёт по четыре Vekniss Hatchling в трёх местах. Отдельный таймер вызывает от одного до трёх червей. Раньше только ассист-танки получали команду атаковать ближайшего адда из общего списка. Теперь мили и дальний DPS выбирают ближайшего Spawn of Fankriss (15630) из отдельного кэша. Ассист-танки продолжают подбирать оба вида аддов. Для основного танка сохранены атака босса и смена ассист-танком по Mortal Wound (25646). Хилы продолжают лечить. Фиксированный маршрут возврата после Entangle пропущен — три точки в скрипте задают места появления аддов, а позиция группы меняется.

## Viscidus

В boss_viscidus.cpp морозные попадания переводят босса в фазу заморозки. Затем ядро считает прямые попадания и проверяет состояние ближней атаки у атакующего при раскалывании. Пока действует Freeze (25937), мили-бот с другой целью переключается на босса. Триггер и действие проверяют ауру. Морозное заклинание теперь повторно проверяет заморозку и наличие глобул перед кастом. Ранее реализованные действия обеспечивают морозные заклинания доступных классов, дистанцию дальников и переключение боевых ролей на глобулы. Хилы сохраняют обычное лечение. Блокировка мили во время накопления мороза пропущена — ядро сохраняет счётчик при обычном ударе.

## Princess Huhuran

В boss_huhuran.cpp Frenzy (26051) и Berserk (26068) раздельны. Снятие доступного для развеивания исступления с текущей цели уже зарегистрировано в GenericHunterStrategy через tranquilizing shot enrage. Рейдовый дубль пропущен. Танк удерживает босса, дальники расходятся, мили продолжают наносить урон, хилы лечат. Мультипликатор ограничивает развеивание Wyvern Sting (26180), за которое ядро наносит цели 3000 урона. Аудит также видит действие выхода из Noxious Poison. Скрипт кастует 26053 на случайную цель и сам по себе не подтверждает создание наземного объекта. Работоспособность существующего выхода из зоны остаётся открытой. Для Poison Bolt ядро сортирует цели по близости при превышении лимита. Гарантированный выбор конкретных игроков по роли из этого условия не следует. Новых действий для Хухуран нет.
